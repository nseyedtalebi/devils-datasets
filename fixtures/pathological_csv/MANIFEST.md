# Pathological CSV fixture set

This directory contains small synthetic CSV fixtures designed to isolate ingestion failure modes. They are deliberately unpleasant but not sensitive: no real source data, no PHI, no credentials, no organization-specific contracts.

Generated by `scripts/generate_pathological_csv.py`; probed against DuckDB by `scripts/probe_duckdb.py`.

Rebuild:

```bash
uv run scripts/generate_pathological_csv.py
```

Probe against DuckDB:

```bash
uv run scripts/probe_duckdb.py
```

DuckDB behavior is version-sensitive. Treat these as regression cases to re-run after engine upgrades, not as eternal claims about any one engine.

## Major findings from the original probe suite

1. **Ragged rows can collapse into a single VARCHAR column instead of failing loudly.** A robust pipeline should detect this shape and either retry narrowly with appropriate options or stop with a clear diagnostic.
2. **Mixed line endings can hard-fail sniffing.** Normalization may need to happen before CSV sniffing.
3. **Non-UTF-8 encodings should fail clearly unless an explicit encoding is supplied.** Beware option differences between engine APIs.
4. **Lenient/error-ignoring modes can create worse behavior than strict failure.** Use them only for named pathologies, not as blanket defaults.
5. **Heuristics such as date-name hints need evidence thresholds.** A column name that sounds temporal is not enough if values are only partly parseable.
6. **“Currently good” behavior deserves regression tests too.** Leading zeros, currency strings, percent strings, and scientific notation can silently change interpretation across engine versions.

## File-by-file index

| file | pathology | expected lesson |
|---|---|---|
| `01_ragged_rows_short.csv` | rows shorter than header | detect ragged collapse; retry or fail explicitly |
| `02_ragged_rows_long.csv` | rows longer than header | detect extra fields; avoid silent row loss |
| `03_trailing_delimiter.csv` | every row ends with stray delimiter | watch phantom empty column behavior |
| `04_single_column_no_delim.csv` | no delimiter anywhere | valid one-column file, not necessarily a failure |
| `05_wide_many_columns.csv` | 300 columns | wide schema stress case |
| `06_header_only_no_rows.csv` | header, zero data rows | empty relation with schema |
| `07_empty_file.csv` | zero-byte file | empty-file behavior |
| `08_embedded_newline_quoted.csv` | newline inside quoted field | quoted multiline handling |
| `09_embedded_delimiter_quoted.csv` | delimiter inside quoted field | quote-aware delimiter handling |
| `10_escaped_quotes_doubled.csv` | RFC4180 doubled quote escaping | standard quote escaping |
| `11_escaped_quotes_backslash.csv` | backslash-escaped quotes | non-default escape character |
| `12_unterminated_quote.csv` | quote opened, never closed | malformed quote behavior |
| `13_inconsistent_quoting.csv` | quoted/unquoted mix row-to-row | inconsistent style tolerance |
| `14_mixed_line_endings.csv` | `\n`, `\r\n`, and `\r` in one file | line-ending normalization before sniffing |
| `15_utf8_bom.csv` | UTF-8 BOM on header | BOM handling |
| `16_latin1_encoding.csv` | Latin-1 bytes in non-UTF-8 file | explicit encoding contract |
| `17_null_bytes_binary_garbage.csv` | embedded NUL/random binary bytes | strict failure vs targeted ignore_errors |
| `18_semicolon_delim_comma_decimal.csv` | semicolon delimiter + comma decimal | dialect and decimal separator |
| `19_pipe_delimited.csv` | pipe delimiter | delimiter detection |
| `20_null_representation_variants.csv` | `NULL`, `NA`, `\N`, `None`, `n/a`, empty | explicit null strings |
| `21_type_flip_late_row.csv` | type flip after default sample window | sampling strategy / full-file sniff |
| `22_numeric_formatting_edge_cases.csv` | thousands separators, currency, percent, scientific notation | numeric inference edge cases |
| `23_leading_zero_ids.csv` | zip/phone/employee IDs with leading zeros | prevent destructive integer coercion |
| `24_boolean_variants.csv` | mixed boolean spellings | BOOLEAN inference ambiguity |
| `25_duplicate_header_names.csv` | repeated column names | positional identity vs name identity |
| `26_ambiguous_date_formats.csv` | several date formats in one column | date inference ambiguity |
| `27_date_hint_edge_cases.csv` | 60% parseable date-like values with name hint | heuristic false-positive guard |
| `28_huge_single_field.csv` | 200k-character field | large cell stress case |
| `29_comment_lines_interspersed.csv` | comment-prefixed lines mixed with data | explicit comment handling |
